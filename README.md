# Blog Platform with Comments

A full-stack blogging application that allows users to create, view, and manage blog posts with an interactive comment system.

## Features
- Create and publish blog posts
- View all blog posts
- Add comments to blogs
- Delete blog posts
- MongoDB database integration
- RESTful API using Express.js
- Responsive and modern user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## How to Run
1. Install dependencies:
   npm install

2. Start MongoDB

3. Run backend:
   node server.js

4. Open frontend/index.html using Live Server
